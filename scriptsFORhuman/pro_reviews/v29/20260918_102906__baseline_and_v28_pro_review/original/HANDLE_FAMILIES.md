# 两指夹握把手：有限形状族与长期接口

状态：讨论建议，非实现批准。出处、页码和限制见`SOURCES.md`中S14–S18、S23；所有非原厂明确标注的轴长、曲率、概率均为工程选择。

## 首批建议

保留当前圆直杆作为对照；新增椭圆直杆、圆角扁直杆，以及中央保持温和曲率的轻弯杆。末端return作为有条件的几何修饰，不另设“钩住即可成功”的任务。FSB1076、1108、1107、1144分别提供量级/外形锚点；GEZE LH103的19 mm圆管证明“oval产品名称”不能直接当椭圆杆。

| 参数 | 工程候选 | 限制 |
|---|---|---|
| 总体杆长度量级 | 110–145 mm | 原厂图纸总长与现generator Capsule轴段长度不是完全相同量，转换时留意弯头/端帽 |
| 圆截面 | 直径18–24 mm | 覆盖19/21 mm锚点，非市场分布 |
| 椭圆截面 | 完整轴长18–24 × 12–18 mm | 是完整轴，不是半轴；不是FSB精确尺寸 |
| 圆角扁截面 | 完整宽20–28、厚10–16 mm | 圆角半径为正，避免尖薄边成为伪抓取点 |
| 主段曲率 | 半径0.2–0.6 m，或50 mm弧长内切向转角≤15° | 与抓握段长度共同约束；不宣称产品实际曲率 |
| return曲率 | 半径15–30 mm | 与杆径、门板净距、碰撞与夹爪扫掠联合过滤 |
| 主抓握自由段 | 初步30–50 mm以上 | 需结合实际指垫宽度，不能拿整个finger mesh宽度替代指垫 |
| 净门板间隙 | 局部插入手指厚度＋工程余量3–5 mm | 全部接近路径还需考虑后段指体；不是硬件安全认证 |
| return概率 | 现有0.5可作为设计对照 | 市场概率未知，最终权重待Owner |

PiPER当前URDF差动行程合计70 mm；完整指体包围盒约56×76.5×26.5 mm。这不等于实测净开口或指垫接触面。末端局部厚度约8–12 mm也不能代表整条接近路径都只需该间隙。

## 建议共用的几何接口

`shape_family, centerline_control_points, section_type, section_axes, section_roll, material_mode, return_spec, door_side, handle_axis_frame, valid_grasp_interval`。

中心线以弧长s描述c(s)，平行移动截面基u(s)/v(s)，避免曲率接近零时Frenet法向翻转。扫掠生成visual；collision用同一中心线/截面作误差受控的凸体组合。完整凸包不能填掉return的内空隙。

主抓握区排除弯头、饰盖、return、过大曲率及门板净距不足段。从有效区间选s_g，位置p=c(s_g)，切向t=normalize(c′(s_g))。把所选接近侧的门板法向投影到t的法平面，得到approach a；closing=t×a。基[a,closing,t]为右手系，随后明确映射到当前PiPER的实际掌部/指爪轴。法向投影退化时换抓握点或采用稳定备用法向，不强行归一化。椭圆/扁截面滚转必须与closing方向联动。

共同输出`grasp_s, grasp_position, tangent, approach, closing, section_frame, free_segment_length, minimum_clearance`给reward、可视化和诊断，避免不同模块各算一个“中点”。左右/推拉转换应使用真实刚体变换与局部轴，不用镜像反射矩阵冒充旋转。

## 接触与质量的一致性

主杆、弯头和return归属同一door_handle刚体；双指接触的目标刚体不变。可以增加接触区域标签识别抓主段还是卡在return，但不得悄悄改变K5有效夹握语义。grasp_target只是跟随handle的参考，不应被变成可碰撞支点。

按空心/实心和材料密度计算每段体积、质量、COM与惯量，使用平行轴定理合并。作为纯形状对照时允许固定总质量，但需相应重算COM/I并明确不是全面实物复刻。概率回钩影响质量、惯量与净空；不能只改visual。分段collision接缝也不应为抓握创造额外卡口。

## 4. 回钩的具体联合采样

采用Pro的圆滑90°弯头，曲率半径R20–30mm、法向回返H=R+b、tip到门面工程间距8mm。端帽保持圆滑，首版轴向伸出r_tip不超过其局部截面的外接半径；实际构造函数返回r_tip，圆截面时等于相应半径。

按以下顺序直接抽取有效组合：

`C=min(60,h−r_tip−8)`；`R~U(20,min(30,C))`；`H~U(R,C)`；`b=H−R`。

最大F2包络r_tip≤17.035516与h55组合时，最保守C≈29.964484mm，因此该组合的R上限约29.964484而不是独立抽30再得到空H区间。其他组合仍可抽到30。全域C至少29.964484>20，保留h与族权重的原定边缘分布；无需重抽门参数或强行裁剪结果。这是Pro“有效条件域”的具体实现次序，不是删减其总体范围。

tip间距8mm与指部空间由不同推导保证，不能混称同一个净空指标。端帽/分段碰撞必须体现这些几何定义，worker不能只改visual。
